# 04 · 国际化

一句话：**文案只在 ARB 里，代码里 `AppLocalizations.of(context)`；带变量的句子必须用占位符。**

## 配置文件

`l10n.yaml`（仓库根）：

```yaml
arb-dir: lib/l10n
template-arb-file: app_en.arb
output-localization-file: app_localizations.dart
output-class: AppLocalizations
nullable-getter: false
```

`pubspec.yaml` 需要两项：`flutter_localizations: {sdk: flutter}`，以及 `flutter: generate: true`。

## 文件

| 文件 | 语言 |
| --- | --- |
| `lib/l10n/app_en.arb` | 英语（模板，`@@locale: en`） |
| `lib/l10n/app_zh.arb` | 简体中文 |
| `lib/l10n/app_zh_Hant.arb` | 繁體中文 |

生成物 `app_localizations*.dart` **也提交在仓库里**，因为它们被 `main.dart` 直接 import；改 ARB 后跑 `flutter gen-l10n`（`flutter pub get` 也会触发）。

繁体中文会折进 `app_localizations_zh.dart` 里作为 `_ZhHant` 子类——找繁体文案去那个文件，不要以为它没生成。

## 键名规范

课件给的规范是 **`页面_元素` / `类别_子类别_元素` / `功能_元素`**，示例 `homepage_title`、`profile_history_title`、`btn_ok` / `btn_cancel`。本仓库采用的映射：

| 课件说法 | 本仓库前缀 | 例子 |
| --- | --- | --- |
| `page_item` | 页面名开头 | `homepage_title`、`detail_title`、`add_title`、`edit_title`、`settings_title` |
| `category_subcategory_item` | 类别_子类别_元素 | `settings_language_system`、`settings_clear_again_body`、`entry_created_on` |
| `function_item` | `btn_` / `dialog_` / `form_` | `btn_save`、`btn_cancel`、`btn_ok`、`dialog_delete_body`、`form_title_hint` |

课件页面里的示例文件用的是简写（`appName`、`appLine`、`getStarted`、`back`、`list`、`titleMissing`、`deleteThisEntry`…），那是**演示用的最小键名**，不是强制格式；规范和示例冲突时以规范（前缀式 snake_case）为准，因为界面一多，`title` 这种裸名字必然撞车。

课件举例、本工程暂未使用因而没有收录的键：`appLine`（副标题 "Capture. Learn. Remember."）、`getStarted`、`now`、`notNow`、`stay`、`leave`、`leaveWithoutSaving`、`photoLibraryAccessNeeded`、`cameraAccessNeeded`、`selectedPhoto`、`changePhoto`、`titleMissing`（本工程用 `dialog_empty_*` + 内联校验替代）。要加「未保存退出确认」时按规范新起 `dialog_leave_*`，不要照抄成裸 `stay` / `leave`。

新增键先在三份 ARB 里加同一把钥匙，再跑生成；缺一份会 fallback 回英文，不报错——这是最容易漏的地方，现在由 `test/l10n_test.dart` 兜住（见下）。

## 占位符（本次课的重点）

```json
"entry_created_on": "Created on {date}",
"@entry_created_on": { "placeholders": { "date": { "type": "String" } } }
```

中文写 `"{date} 建立"`。**不要**用 `"$date 建立"` 拼字符串——语序、标点、数字格式都会各写一套。

复数用 `type: "int"` + `plural`：

```json
"settings_clear_body": "{count, plural, =1{This will delete 1 entry and all photos.} other{This will delete {count} entries and all photos.}}"
```

## 日期与数字

- 日期：`formatEntryDate(DateTime, localeName)`（`lib/Utils/formatters.dart`），内部 `DateFormat.yMMMd` + 异常回退 `yyyy-MM-dd`。
- localeName 在页面里取：`AppSettings.codeOf(Localizations.localeOf(context))`。
- 字节大小：`formatStorageSize(int)` **向下取整**，所以清空后一定显示 `0 KB`——如果改成四舍五入，`0.6 KB` 会显示成 `1 KB`，Challenge 的验收会挂。

## 语言状态

`AppSettings`（`lib/Utils/app_settings.dart`）持有 `localeCode`：

- `system` → `MaterialApp.locale = null`，跟随系统
- `en` / `zh` / `zh_Hant` → 显式 `Locale`
- 写 SharedPreferences 键 `app.locale`；启动时 `await load()` 之后才 `runApp`，首帧语言即正确。

`SettingsPage` 只调 `settings.setLocaleCode(...)`；`main.dart` 的 `ListenableBuilder(listenable: settings)` 负责重建 `MaterialApp`。

## 三条自动守住的红线

`test/l10n_test.dart`（AC-S3-16）把 i18n 的技术债变成三条会红的断言：

1. **键集一致**：`app_zh.arb` / `app_zh_Hant.arb` 的键必须与 `app_en.arb` 完全相同，多一个少一个都失败。
2. **占位符一致**：`{date}`、`{count}`、`{title}` 这类占位符在三语里必须同名同数量——语序可以变，变量名不能变。
3. **没有死键**：模板里的每个键都必须在 `lib/`（排除生成的 l10n 文件）里被引用；不许留下没人用的字符串。

改文案、加语言、删控件时跑 `flutter test test/l10n_test.dart`，漏改的那一侧会直接点出来。
