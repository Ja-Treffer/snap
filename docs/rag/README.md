# EduSnap · RAG 知识库

这是 `demo_pages` 仓库的**检索用文档集**：不是从头读到尾的手册，而是给「先检索、再回答」准备的。每篇只讲一个面，标题和开头一句就能判断要不要细看。

## 为什么有这一套

仓库只有 ~1500 行 Dart，但信息密度不低：分层约定、key 名、ARB 键名、平台配置、测试注入缝，散在十几个文件里。整棵树塞进上下文既贵又噪声大，而检索时最怕读到过期实现（旧路径残留在注释里）。这套文档的做法是：**先把「现在的真相」写成人能核对的几句话，再指回具体文件**。

代价是文档会过期。每篇末尾有「最后核对」标记，改动了对应模块就顺手更新那一篇。

## 三条阅读前提

1. **这是课堂工程，不是产品。** 范围以 `PROJECT_SPEC.md` 为准，超出范围的功能写进台账而不是顺手加进来。
2. **路径一律带目录前缀。** `AddPage.dart`、`HomePage.dart` 这种裸名在多处出现，检索会撞。
3. **代码即真相。** 文档与代码冲突时以 `lib/` 为准，然后回来把这段改掉。

## 文档边界

不写这些：课件原文（看 `PROJECT_SPEC.md §13`）、里程碑计划（看 `SESSION3_PLAN.md`）、教学笔记（看 `SESSION3_NOTES.md`）。重复一份只会互相打脸。
